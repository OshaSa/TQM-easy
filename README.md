# TQM easy

نظام متابعة اختبار الجودة (ملاحظات، إسناد، إعادة اختبار، اعتماد الجاهزية). يعمل كصفحة واحدة ويخزّن البيانات في Supabase.

## رابط البرنامج

https://ayeshashadi5-sudo.github.io/TQM-easy/
https://oshasa.github.io/TQM-easy/

## التشغيل

1. أنشئ مشروعاً مجانياً على https://supabase.com
2. من SQL Editor شغّل محتوى الملف supabase_setup.sql
3. من Project Settings ثم API Keys انسخ مفتاح Publishable key (أو anon في Legacy API Keys)، ومن Data API انسخ Project URL
4. ضع القيمتين في ملف config.js
5. فعّل GitHub Pages: من Settings ثم Pages اختر Deploy from a branch، ثم main، ثم root
6. افتح رابط البرنامج أعلاه

## أول دخول

الاسم: admin

كلمة السر: 1234

غيّرها من إدارة المستخدمين بعد أول دخول.

## تنبيه أمني

المفتاح ظاهر لأي زائر، والسياسة الحالية تسمح بالقراءة والكتابة للجميع، فأي شخص يملك الرابط تقنياً يقدر يقرأ المستخدمين وكلمات السر. مناسب للتجربة والفرق الصغيرة فقط.
